# Campus Safety AI — Phase 2 Evidence MVP

Run:
```powershell
pip install -r requirements.txt
python app.py
```
Open http://127.0.0.1:5000

Adds: YOLO tracking, evidence snapshots, vehicle/direction metadata, incident evidence links, and human-review statuses. The traffic direction rule is a configurable demo heuristic and must be verified by an authorized person. Use synthetic/demo footage and data for the hackathon.
